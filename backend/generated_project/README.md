# Unified Adaptations Project

## Architecture Blueprint
Unified change detection flow: Bi-temporal image patches ➔ Visual backbones feature extraction ➔ Adaptive Fusion Network ➔ Change Decoder ➔ Binary output change mask.

## Requirements
Python 3.10+, PyTorch 2.0+, CUDA 11.8+, psutil, numpy, scikit-learn. Host VRAM target limit: 8.0 GB.
